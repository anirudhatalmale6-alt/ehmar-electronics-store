ehmar.com — add many products at once

Fill in one spreadsheet with all your products, upload it, and they all appear on the website in one go. Best for 200+ products.

In short: open the template → one row per product → save as CSV → Products → Import → Continue → Run the importer. Tip: try with 5 products first, check them on the website, then import the rest.

1. Open the template

Open the file ehmar-products-template.csv (sent with this guide) in Excel, Numbers or Google Sheets. It already has 3 example products — replace them with yours and add as many rows as you need.

Keep the first row (the column titles) exactly as it is.

2. What to put in each column

ColumnWhat to type
TypeAlways simple. (Products with choices such as colours or sizes are easier to add one by one, as in the first guide, or send them to me.)
SKUYour own unique code for each product, e.g. EH-0004, EH-0005… Never use the same code twice.
NameThe product name customers see.
Published1 = visible on the website, 0 = saved but hidden (draft).
Short descriptionOne or two lines shown next to the price.
DescriptionFull details: specifications, what is in the box, warranty.
Regular pricePrice in US dollars, numbers only, no $ sign: 89.00
Sale priceOptional. If filled, the regular price is shown crossed out.
CategoriesExactly one of: Security Cameras, Video Doorbells, Phones & Tablets, Electronics, Solar Power, Kitchen, Car Accessories. (A new name creates a new category.)
In stock?1 = in stock, 0 = out of stock.
StockHow many you have, e.g. 10. Leave empty if you don't track quantities.
ImagesWeb link of the photo (starting with https://). Several photos: separate the links with a comma, the first one is the main photo. You can also leave it empty and add photos later in the product.

Where to get photo links: on a supplier's page, right-click the photo → Copy image address. Or upload your own photos in the dashboard under Media → Add New, click a photo and use Copy URL to clipboard.

3. Save the spreadsheet as CSV

  • Numbers (Mac): File → Export To → CSV… → Next → Save.
  • Excel: File → Save As → choose CSV UTF-8 (Comma delimited).
  • Google Sheets: File → Download → Comma-separated values (.csv).

Always save from the spreadsheet program like this — don't edit the CSV file in a plain text editor, or the columns can get mixed up.

4. Upload it: Products → Import

Log in at ehmar.com/wp-admin, click Products → All Products, then the Import button at the top.

5. Choose your file and click Continue

Click Choose file, pick your CSV, then Continue. (Only to change prices of products already on the site: tick Update existing products — products are matched by SKU.)

6. Columns are matched for you — click Run the importer

Because you used the template, every column is already matched. Scroll down and click Run the importer.

7. Done — check your new products

When it says Import complete, click View products. Your new products are at the top of the list, with price, sale price, stock and category, and they are already on the website.
